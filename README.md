# C Programming: Coursework & Projects

A structured repository for C programming coursework, daily practice exercises, and integrated software projects.

## Overview
This repository serves as a centralized portfolio for my C programming coursework and independent projects. It contains practical implementations of concepts covered in my classes, designed to build a robust foundation in algorithmic problem-solving, memory management, and data structures.

## Repository Structure
* **`/practice`**: Daily academic exercises demonstrating core C concepts, including control flow, file I/O, and pointer manipulation.
* **`/data_structures`**: Implementations of fundamental structures taught in class, such as linked lists, stacks, queues, and binary trees.
* **`/algorithms`**: Searching and sorting algorithms, alongside time-complexity optimization practices.
* **`/projects`**: Integrated applications that combine multiple concepts to solve complex problems or simulate real-world utilities.

## Environment & Tools
* **Language**: C
* **Compiler**: GCC
* **Environment**: WSL (Ubuntu) / Linux

## Compilation and Execution
Source files are standard C and can be compiled using GCC. To compile and execute a specific file from your WSL terminal:

```bash
# Compile the source code
gcc -o program_name filename.c

# Execute the compiled binary
./program_name
